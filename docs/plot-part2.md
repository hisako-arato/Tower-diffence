# 第二部 プロット（第3章〜第5章）

確定事項：エンディングはA（王の勝利）。英雄が使えなくなるのは第二部のステージだけ（第一部・イベントでは従来通り使える）。

## 第3章「裏切りの夜」（通常の防衛・5ステージ）【実装済み】
- Ⅱ3-1 王の帰還：ルミナが王都へ逃げ警鐘。英雄たちはまだ知らない。主人公「ルミナが錯乱した」。敵：光の使徒（光属性の天使型）。
- Ⅱ3-2 真実の光：ルミナが広場で千年前の記憶を見せる（王は「永遠」＝死と終わりのない世界を求め、神ルミナが封じた）。★3の騎士団が離脱。カリン「やっぱり、同じ匂いだった」。以後第二部で★3使用不可。
- Ⅱ3-3 裏切りの夜：★4たちが天幕を囲む。ブレア「あんたの口から聞かせな」→主人公「すべて本当だ」。★4離脱。リンの結晶からリヴァイア復活・加入。
- Ⅱ3-4 追う者たち：前のストーリーでリディア以外の★5が離脱（ネレイア「言ったでしょう。次は敵よ」）。カグラを先頭に★4たちが追撃し、カグラ本人もボスとして登場。使えるのはリディアと闇の配下だけ。カグラ「星は、あなたの敗北を告げていません。だから、わたしが変えます」。
- Ⅱ3-5 騎士姫：玉座跡でオルドラ復活・加入（戦闘前）→リディアと二人きり。剣を向けるが刺せず去る。敵：リディアの命を受けた王都騎士団長と騎士団。全英雄使用不可（闇の配下とリンだけで戦う）。【実装済み】

## 第4章「災厄の行進」（攻守反転・5ステージ）【実装済み】
- Ⅱ4-1 王都外壁：★3騎士団が守る（R-1を本番化）→アルゴス復活
- Ⅱ4-2 蒼の神殿：セイラ・ミナモほか→ヴェルミナ復活
- Ⅱ4-3 白銀の古城：カグラほか→アストレア復活（配下6人そろう）
- Ⅱ4-4 紅蓮の火口：ブレア・カリンほか
- Ⅱ4-5 天への階：★5、最後にリディア→英雄たちは神の座へ退く
- 復活した配下は反転バトルの権能カードになる（例：リヴァイア「大海嘯」英雄の攻撃を遅く、オルドラ「原初の咆哮」魔物強化）。
- 各話で配下が千年前に王へ仕えた理由を語る。章末：ルミナ「来なさい、{name}さま。……最後は、わたしが」

## 第5章「神の座」（1ステージ・3段階、使えるのは闇の配下6人）【実装済み】
- 第1段階：★4の12人＋★3の9人（ガルド・ミア・カイ・トーマス・リリィ・毒の4人）。撃破時に台詞。
- 第2段階：★5の7人、最後にリディア。「遠くを見る目、最後まで変わらなかったわね」
- 第3段階：神ルミナ。「終わりがあるから、人は誰かを大切にできる」／主人公「それでも俺は、誰も失わない世界がほしかった」
- エンディングA：主人公が神の座につき、世界から「終わり」が消える。英雄たちは眠ったまま永遠の中に。リンだけがそばに残り「お帰りなさいませ、我が主」で幕。

## 闇の配下3人（決定）
- アルゴス（千眼の災厄）：光・魔導。発動スキル「千の目の光線」＝射程に関係なくフィールドの敵すべてを目が撃つ（敵が多いほど強い）。
  過去：王の行く末を見たいだけ。忠誠ではなく好奇心で仕えている。
- ヴェルミナ（腐蝕の災厄）：闇・弓。通常攻撃で毒を2ずつ。発動スキルで射程内の敵の毒を一気に最大（猛毒）にする。
  過去：世界を腐らせたい。王の「永遠」は、腐り続けても終わらない世界だと思っている。
- アストレア（天秤の災厄）：光・僧侶。発動スキル「天秤の裁き」＝味方全員を回復し、回復量と同じダメージを射程内の敵へ。
  過去：王を裁くために側にいる。王が道を誤れば、その時に天秤を傾けるつもり（第5章に不穏さを残す）。
- 3人の思惑がばらばらなことは、第4章の各話で少しずつ見せる。

## 第5章の仕様（決定）
- 1ステージで3段階を通しで戦う。負けたら第1段階から（チェックポイントなし）
- 段階が変わっても、配置・HP・魔力・ライフ・スキルゲージはすべてそのまま引き継ぐ（消耗戦）
- 神ルミナの仕掛け「封印の光」：一定時間ごとに配下を1人選び、数秒間封印する（攻撃もスキルも止まる）。封印される配下には予兆が出る
- エンディングA：ストーリーのあと、登場キャラの顔が流れるエンドロール。最後にリンの「お帰りなさいませ、我が主」で幕
