# キャラ画像の差し替え

このフォルダに画像を置くと、SVGのオリジナルアートの代わりに表示できます。

1. 画像をこのフォルダに置く（例：`lydia.png`）。推奨は正方形〜縦長の透過PNG
2. `js/art.js` の `TD.CUSTOM_ART` に1行追加する
   ```js
   TD.CUSTOM_ART = {
     lydia: 'assets/chars/lydia.png',
   };
   ```
3. `sw.js` の `VERSION` を上げてから公開する（インストール済みアプリにも反映させるため）

画像はWeb上で誰でもダウンロードできる状態になります。
利用規約で「Webゲームでの使用」が認められている素材だけを使ってください。
