# 結界の守り手 — Guardians of the Barrier

剣と魔法の世界を舞台にした、ソシャゲ風キャラクター配置型タワーディフェンス。
ブラウザだけで動きます（サーバー・ライブラリ不要）。スマホ縦画面推奨。

## 遊び方

GitHub Pages の URL にアクセスしてください（`index.html` を直接開いても遊べますが、アプリ化・オフライン対応は http(s) 経由のときのみ有効です）。

### アプリとしてインストール（PWA）
- **Android / PC の Chrome・Edge**：ホーム画面の「アプリ版をインストール」ボタン、または 設定 →「ホーム画面に追加する」
- **iPhone / iPad（Safari）**：共有ボタン（□↑）→「ホーム画面に追加」
- インストール後は全画面で起動し、一度読み込めばオフラインでも遊べます

1. ホームの「出撃」からステージを選ぶ
2. 下のカードをタップ → 光ったマスをタップで配置（マナを消費）
   - **剣士・盾騎士** は「道」に配置。敵をブロックして足止めする
   - **弓兵・魔導士・僧侶** は「草地」に配置
3. 必殺技ゲージが溜まったら（カードが金色に光る）カードをタップで必殺技
4. 配置済みのキャラをタップ → 必殺技／撤退（マナ半分返却）
5. 敵を全滅させればクリア。残りライフで ★1〜3 の評価

### 召喚・育成
- **召喚**：魔晶石（ゲーム内アイテム）で英雄を召喚。1回30 / 10回300。現実のお金は一切使いません。
  - 排出率：★5 3%（6人）／★4 17%（12人）／★3 80%（18人）。ピックアップはなし（常設の「英雄召喚」のみ）
  - 10回召喚は★4以上1体確定、100回目は★5確定
  - **限界突破が最大（4回）になったキャラは排出されない**（そのレアリティの残りのキャラの確率が上がる）
- **レベルアップ**：ステージで手に入る「経験の書」を使う。上限は Lv20（限界突破1回ごとに +10）
- **限界突破**：同じキャラが重なると最大4回まで突破。ステータスと上限レベルが上がる
- 初回起動時に魔晶石900個をプレゼント

### ★3キャラ
★3は18人。初心者の戦力として扱いやすく、サポート専門のキャラもいます。
- **ソヨ（風・癒）【バフ専門】**：配置するだけで周囲2マスの味方の攻撃速度+15%。必殺技で全員の攻撃速度1.4倍
- **ルクス（光・弓）【デバフ専門】**：必殺技で射程内の敵の防御を10秒間半減

### ストーリー
- 初回起動時にプロローグ（名前入力あり）。ステージの前後に会話パートが入る
- タップで送る／AUTO で自動送り／LOG で履歴／SKIP で飛ばす
- 既読のエピソードはホームの「ストーリー」からいつでも見返せる

### 毎日のお楽しみ
- **ログインボーナス**：毎日0時（端末の時刻）に更新。7日周期で、7日目は魔晶石300
- **デイリーミッション**：勝利・撃破数・必殺技・レベルアップなど。全部達成でボーナス
- **通常ミッション**：ステージ攻略・英雄集め・通算記録などの一度きりの目標
- **デイリークエスト「古代の書庫」**：経験の書が大量に手に入る（1日3回まで、1-1クリアで解放）
- **期間限定イベント「星降る夜の魔導祭」**（2026/11/15〜12/14）：イベントストーリー、通常・上級ステージ、
  「星の欠片」を集めて交換所で★4ルーンや魔晶石と交換

### キャラクターアート
全13キャラ分のオリジナルのイラストを SVG で描画しています（`js/art.js`）。外部素材は使っていません。
レアリティが高いほど豪華になります。
- ★3：シンプルな衣装・銀枠
- ★4：金縁の衣装・宝石・淡いオーラ・紫枠
- ★5：回転する光条・マント・舞う粒子（羽／氷／葉）・光る武器・金枠＋光沢

画像に差し替えたい場合は `assets/chars/README.md` を参照してください。

### 敵の攻撃
- 近接の敵は、足止めしている剣・盾を攻撃する
- **遠距離の敵**（ゴブリン弓兵・闇の魔導兵）は、歩きながら射程内のキャラを撃つ（弓・魔・癒も狙われる）。1-3 から登場
- **ボスの範囲攻撃**：赤い円の予兆が出た約2秒後に、円の中のキャラ全員にダメージ。撤退でかわせる

### ★4キャラの役割
★4は数値では★5に劣っても、★5にはない役割を持つように設計しています。
- 低コスト（8）・⚡高速再配置で、序盤から置けて出し入れしやすい
- ★4だけの効果：撃破でマナ回復（アカネ）、味方の必殺技ゲージを増やす（シズク）
- ゲーム中でその★4しかいない属性×職業の組み合わせ（風・剣、闇・弓、闇・盾、火・癒、水・弓）
- 挑発で遠距離攻撃・ボスの範囲攻撃を引きつける（ゼノ）、味方全体の攻撃力アップ（カリン）、味方全体の被ダメージ軽減（シグレ）

### 撤退と再配置
- 撤退するとマナが半分戻る
- 撤退時の待ち時間は **残りHPが多いほど短い**（下限5秒）：`待ち時間 = max(5秒, 再配置時間 × (1 − 残りHPの割合))`
  - 例：再配置時間30秒のキャラ → HP満タンで撤退すると5秒、HP半分で15秒、やられると30秒
- 撤退メニューに、今撤退した場合の待ち時間が表示される

### キャラの個性（特性）
キャラ定義（`js/data.js` の `TD.CHARS`）に `traits: ['fastRedeploy']` と書くと特性を持たせられます。
| 特性 | 効果 |
|---|---|
| ⚡ 高速再配置（`fastRedeploy`） | 再配置までの待ち時間が半分（撤退時の下限5秒は共通） |

新しい特性は `TD.TRAITS` に追加します。

### 属性相性
属性は 光・闇・水・火・風 の5種類。火 → 風 → 水 → 火（矢印の先に1.5倍、逆は0.75倍）。光と闇は互いに1.5倍。

## イベントの差し替え方
`js/data.js` の `TD.EVENT` を書き換えます（`start` / `end` で開催期間、`stages` でステージ、`shop` で交換所）。
イベントストーリーは `js/story.js` の `TD.STORY['event-…']` に追加し、`TD.EVENT.story` に ID を指定します。
`id` を新しい値にすると、イベントポイントや交換回数は新イベント用にリセットされます。

## 更新時の注意
`sw.js` の `VERSION` を上げてから公開すると、インストール済みアプリにも確実に新しいファイルが配信されます。
