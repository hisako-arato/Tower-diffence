# Tower Defense

ブラウザで動くシンプルなタワーディフェンスゲーム（依存ライブラリなし・HTML 1枚）。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。ローカルサーバーで動かす場合:

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 操作

| 操作 | 内容 |
|---|---|
| タワーボタン / `1`〜`4` | 設置するタワーを選択 |
| 草地をクリック | タワーを設置 |
| 売却モード / `s` | タワーをクリックで売却（60%返金） |
| 次のウェーブ / `Space` | ウェーブ開始 |
| 速度ボタン | x1 / x2 / x3 切替 |

## タワー

| 名前 | コスト | 特徴 |
|---|---|---|
| 砲台 | 50 | バランス型 |
| 連射 | 80 | 射程短め・高速連射 |
| 狙撃 | 120 | 長射程・高威力・低速 |
| 冷気 | 90 | 命中した敵を減速 |

敵は Wave 3 から高速型、Wave 5 から重装型、5 ウェーブごとにボスが出現します。ライフが 0 になるとゲームオーバー。
