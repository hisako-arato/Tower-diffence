# 結界の守り手 — Guardians of the Barrier

剣と魔法の世界を舞台にした、ソシャゲ風キャラクター配置型タワーディフェンス。
ブラウザだけで動きます（サーバー・ライブラリ不要）。スマホ縦画面推奨。

## 遊び方

GitHub Pages の URL にアクセスしてください（`index.html` を直接開いても遊べますが、アプリ化・オフライン対応は http(s) 経由のときのみ有効です）。

### アプリとしてインストール（PWA）
- **Android / PC の Chrome・Edge**：ホーム画面の「アプリ版をインストール」ボタン、または 設定 →「ホーム画面に追加する」
- **iPhone / iPad（Safari）**：共有ボタン（□↑）→「ホーム画面に追加」
- インストール後は全画面で起動し、一度読み込めばオフラインでも遊べます

1. ホームの「出撃」からステージを選ぶ
2. 下のカードをタップ → 光ったマスをタップで配置（マナを消費）
   - **剣士・盾騎士** は「道」に配置。敵をブロックして足止めする
   - **弓兵・魔導士・僧侶** は「草地」に配置
3. スキルゲージが溜まったら（カードが金色に光る）カードをタップでスキル
4. 配置済みのキャラをタップ → スキル／撤退（マナ半分返却）
5. 敵を全滅させればクリア。残りライフで ★1〜3 の評価

### スキルの種類
- **発動スキル**：ゲージが溜まったらタップで発動／**常時スキル**：配置中ずっと有効。1人はどちらか1つだけ持つ
- **ユニークスキル**：一部のキャラだけが持つ特別な効果（スキル欄の下に表示）。高速再配置、ソヨ「天使の加護」（自身のHPが減らない）、ヴィオラ「蝕みの呪い」（毒状態の敵へのダメージ2倍）、下の出撃メンバー効果など

### 状態異常：毒
- 敵の毒：1つごとに毎秒、最大HPの1%（最大5つ・5秒、ボスは1/3）
- カゲロウ「毒の刃」：攻撃ごとに毒+1／ヴィオラ「呪毒の霧」：範囲攻撃で毒+2
- ルナ「鈍化の矢」：当てた敵の移動速度-30%（3秒）／トマス「盾撃ち」：攻撃が敵2体に当たる
- 敵「毒沼のスライム」（第2章）は攻撃した味方を毒にする（毎秒最大HPの2%・6秒）。リリィ「浄化の泉」の回復で解除

### 副官
- 出撃メンバーの1人目は**召喚士の副官**。ホーム画面に大きく表示され、タップするとセリフを話す
- 副官はバトルで **HP・攻撃・防御 +20%**（カードとキャラに王冠の印）
- 編成画面のキャラ詳細から「👑 副官に任命」
- **副官以外の5人は★の合計が22以下**になるようにしか編成できない（超えている編成では出撃不可）

### 召喚・育成
- **召喚の儀**：召喚士は、大陸に散った「英雄の魂の欠片」を魔晶石（ゲーム内アイテム）で呼び寄せる。1回30／10回300。現実のお金は一切使いません。
  - はじめての欠片で英雄が仲間になり、2つ目からは限界突破（最大4回）。英雄1人につき欠片は5つ
  - 呼び寄せやすさ：★5 3%（6人）／★4 17%（12人）／★3 80%（19人）
  - 欠片がすべて集まった英雄は現れない。ある★の欠片が尽きると、その★は現れず残りの★で分け直す
  - 10回召喚では★4以上の欠片が必ず1つ（残っていれば）。天井（一定回数で★5確定）はなし
  - すべての欠片が集まると召喚できなくなる
- **レベルアップ**：ステージで手に入る「経験の書」を使う。上限は Lv20（限界突破1回ごとに +10）
- **限界突破**：同じキャラが重なると最大4回まで突破。ステータスと上限レベルが上がる
- 初回起動時に魔晶石900個をプレゼント

### 敵の攻撃
- 近接の敵は、足止めしている剣・盾を攻撃する
- **遠距離の敵**（ゴブリン弓兵・闇の魔導兵）は、歩きながら射程内のキャラを撃つ（弓・魔・癒も狙われる）。1-3 から登場
- **ボスの範囲攻撃**：赤い円の予兆が出た約2秒後に、円の中のキャラ全員にダメージ。撤退でかわせる

### 攻撃間隔（職業ごとに固定）
| 剣士 | 弓兵 | 魔導士 | 盾騎士 | 僧侶 |
|---|---|---|---|---|
| 0.9秒 | 1.0秒 | 1.9秒 | 1.4秒 | 1.6秒 |

キャラごとの火力の差は攻撃力（と常時スキル）で表す。

### 撤退と再配置
- 撤退するとマナが半分戻る
- 撤退時の待ち時間は **残りHPが多いほど短い**（下限5秒）：`待ち時間 = max(5秒, 再配置時間 × (1 − 残りHPの割合))`
  - 例：再配置時間30秒のキャラ → HP満タンで撤退すると5秒、HP半分で15秒、やられると30秒
- 撤退メニューに、今撤退した場合の待ち時間が表示される

### キャラの個性（特性）
キャラ定義（`js/data.js` の `TD.CHARS`）に `traits: ['fastRedeploy']` と書くと特性を持たせられます。
| 特性 | 効果 |
|---|---|
| ⚡ 高速再配置（`fastRedeploy`） | 再配置までの待ち時間が半分（撤退時の下限5秒は共通） |

新しい特性は `TD.TRAITS` に追加します。

### 属性相性
属性は 光・闇・水・火・風 の5種類。火 → 風 → 水 → 火（矢印の先に1.5倍、逆は0.75倍）。光と闇は互いに1.5倍。

## イベントの差し替え方
`js/data.js` のイベント定義（`TD.EVENT` など）を書き換え、`TD.EVENTS` に並べます（`start` / `end` で開催期間、`stages` でステージ、`shop` で交換所）。
イベントストーリーは `js/story.js` の `TD.STORY['event-…']` に追加し、イベントの `story` に ID を指定します。
`eventOnly: true` の英雄は召喚に出ず、交換所の `char` 商品でのみ入手できます。
`id` を新しい値にすると、イベントポイントや交換回数は新イベント用にリセットされます。

## 更新時の注意
`sw.js` の `VERSION` を上げてから公開すると、インストール済みアプリにも確実に新しいファイルが配信されます。
