# 結界の守り手 — Guardians of the Barrier

剣と魔法の世界を舞台にした、ソシャゲ風キャラクター配置型タワーディフェンス。
ブラウザだけで動きます（サーバー・ライブラリ不要）。スマホ縦画面推奨。

## 遊び方

`index.html` をブラウザで開くか、GitHub Pages の URL にアクセスしてください。

1. ホームの「出撃」からステージを選ぶ
2. 下のカードをタップ → 光ったマスをタップで配置（マナを消費）
   - **剣士・盾騎士** は「道」に配置。敵をブロックして足止めする
   - **弓兵・魔導士・僧侶** は「草地」に配置
3. 必殺技ゲージが溜まったら（カードが金色に光る）カードをタップで必殺技
4. 配置済みのキャラをタップ → 必殺技／撤退（マナ半分返却）
5. 敵を全滅させればクリア。残りライフで ★1〜3 の評価

### 属性相性
火 → 風 → 土 → 水 → 火（矢印の先に1.5倍）。光と闇は互いに1.5倍。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面構成（タイトル・ホーム・クエスト・編成・バトル） |
| `css/style.css` | デザイン |
| `js/data.js` | **キャラ・敵・ステージのデータ**（ここを編集すれば追加できる） |
| `js/save.js` | セーブ（localStorage）・引き継ぎコード |
| `js/battle.js` | バトルエンジン |
| `js/app.js` | 画面遷移・UI |
